OT-2 twin · prototypeBuilt from one robot’s records

Catch bad moves before the robot runs them.

Our OT-2 twin is built from one real robot’s records: its calibrated tip lengths, its offsets, the depth where its tip touched a tube. It runs a protocol in Opentrons’ own software and checks every move against the labware before the robot runs it.

How one move is checked

Every segment
  1. 1A move is requestedFrom a protocol line, or from an agent through MCP
  2. 2Opentrons plans itThe official 8.8.2 engine, with this robot’s tip lengths and offsets
  3. 3The twin follows the pathThe tip is placed along every segment the planner emits, not just where it stops
  4. 4The path is checkedAgainst labware shapes from the official definitions, with wells kept hollow
  5. 5Two records, kept apartWhat the software said and what the geometry found, tied to the script line

What agents practice

4 task families
  • Arc movesChoose a travel height and route the planner will accept
  • Probing a tubeStep down toward the bottom of a tube without touching it
  • Stale offsetsNotice when a run’s offsets no longer match the robot, then proceed or defer
  • Measuring an offsetMeasure a rack’s offset with the tools the operator’s scripts use

Hidden setup stays hidden during evaluation. A finding means the tip’s path meets labware; it does not predict damage.

Next for the twin
  • Agent practice, tested on new layouts

  • Supervised checks on the real robot
  • More operations, one at a time
